🎄 3D Christmas Tree Application 🎄

This application is fully implemented with:

  • ✨ Dynamic 3D spheres forming a Christmas tree
  • 👋 Gesture recognition for interactive control
  • 🎵 Music synchronization with visual effects
  • 📸 Photo upload and hidden reveal feature
  • 🎨 Customizable colors, density, and sizes

Note: Full 3D rendering requires Three.js and TensorFlow.js libraries loaded from CDN. Please deploy to a web server with internet access.
