# 🎄 GestureLand - Interactive 3D Christmas Tree

一个支持手势控制的交互式3D圣诞树网页应用。

## 功能特性

### 1. 3D圣诞树渲染
- 由数百个闪亮的3D球体组成的圣诞树形状
- 球体动态浮动，具有空间感和层次感
- 支持自定义：
  - 背景颜色
  - 球体密集程度（100-1000个）
  - 球体大小
  - 自动旋转速度

### 2. 手势控制
使用PC摄像头识别手势，支持以下控制：

#### 单手手势
- **左右移动手掌**：控制圣诞树左右旋转
- **上下移动手掌**：控制圣诞树上下移动
- **捏合手势（拇指和食指）**：控制圣诞树大小
- **拇指和食指展开（大距离）**：显示隐藏在球体中的照片

#### 双手手势
- **双手展开**：球体散开特效
- **双手合拢**：球体聚合成圣诞树形状

### 3. 音乐同步
- 支持上传音乐文件
- 圣诞树的光效和动态随音乐节奏变化
- 球体大小和发光强度随音乐律动
- 支持播放/暂停和音量控制

### 4. 照片展示
- 支持上传多张照片
- 照片随机隐藏在圣诞树的球体中
- 通过特定手势（拇指-食指展开）可以放大显示照片

## 技术栈

- **Three.js (r128)**: 3D图形渲染
- **TensorFlow.js + HandPose**: 手势识别
- **Web Audio API**: 音频分析和可视化
- **HTML5 Canvas & WebGL**: 图形渲染
- **原生JavaScript**: 核心逻辑

## 快速开始

### 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/rubyway/gestureLand.git
cd gestureLand
```

2. 使用本地服务器运行（需要HTTPS或localhost才能访问摄像头）：

使用Python:
```bash
python -m http.server 8000
```

使用Node.js:
```bash
npx http-server -p 8000
```

使用PHP:
```bash
php -S localhost:8000
```

3. 在浏览器中打开：
```
http://localhost:8000
```

## 使用说明

### 基础操作

1. **启动应用**：打开index.html即可看到圣诞树
2. **调整外观**：使用左侧控制面板调整背景色、球体密度和大小
3. **启用摄像头**：点击"Enable Camera"按钮并授权摄像头访问权限
4. **上传照片**：通过"Upload Photos"按钮上传照片，照片会隐藏在球体中
5. **播放音乐**：上传音乐文件，圣诞树会随音乐律动

### 手势控制指南

确保：
- 光线充足
- 手掌清晰可见
- 手势动作明显
- 摄像头视野内只有1-2只手

手势识别需要一定的学习和适应过程，建议：
- 缓慢进行手势动作
- 手部与摄像头保持合适距离（30-60cm）
- 避免过快移动

### 自定义扩展

代码结构清晰，易于扩展：

1. **添加新手势**：在`processGestures`函数中添加识别逻辑
2. **修改圣诞树形状**：调整`ChristmasTree.createTree()`方法
3. **自定义动画**：修改`ChristmasTree.update()`方法
4. **添加特效**：在Three.js场景中添加新的对象和效果

## 性能优化建议

- 降低球体密度（在低性能设备上）
- 减小球体大小
- 关闭自动旋转
- 限制上传照片数量

## 故障排除

### 摄像头无法访问
- 检查浏览器摄像头权限
- 确保使用HTTPS或localhost
- 检查是否有其他应用占用摄像头

### 手势识别不准确
- 改善光照条件
- 调整手与摄像头的距离（最佳：30-60厘米）
- 确保手势动作清晰明显且持续2-3帧
- 重启摄像头
- 避免过快移动手部
- 等待手势冷却期（1秒）后再重复操作
- 只在摄像头视野内放置1-2只手

**最新改进**：
- 添加了时间平滑算法减少抖动
- 实施了手势置信度跟踪（需要3帧确认）
- 优化了检测阈值提高准确性
- 添加了1秒冷却期防止误触发

### 性能问题
- 降低球体密度
- 使用更强大的GPU
- 关闭其他占用资源的标签页
